ملف أعمال وجدان القرني — طريقة الرفع على GitHub Pages
==========================================================

1) محتويات المجلد
   index.html   ← الصفحة الرئيسية (لازم يبقى بهذا الاسم)
   style.css    ← الألوان والتصميم
   script.js    ← الحركة والعدّادات والوضع الداكن
   images/      ← كل الصور والمقاطع (جاهزة ومصغّرة، وكل ملف باسمه الصحيح)
   cv.pdf       ← سيرتك الذاتية (الملف الموجود الآن مؤقت: استبدليه بملفك بنفس الاسم cv.pdf)

2) الصور والمقاطع
   - ارفعي مجلد images كاملًا مع الملفات. أي ملف ناقص تظهر مكانه خانة «صورة هنا» باسم الملف المطلوب.
   - لإضافة صورة لاحقًا: سمّيها باسم الحملة ثم رقم، مثل launch-1-3.jpg، وتظهر تلقائيًا بعد الصور الموجودة.
   - المقاطع: الملفات mp4 داخل images، أو روابط يوتيوب / تيك توك / إنستقرام داخل index.html.
     (ابحثي في index.html عن  data-embed  وغيّري الرابط.)
   - الشعارات داخل images/logos.

3) الروابط اللي تتبدّل (افتحي index.html وابحثي عن كلمة TODO)
   #TODO-linkedin   ← رابط لينكدإن
   #TODO-whatsapp   ← رابط واتساب
   #TODO-email      ← mailto:بريدك
   المهن المتحركة في الرئيسية ← من ملف index.html ابحثي عن  roles-data

4) الرفع
   GitHub ← Add file ← Upload files ← اسحبي كل الملفات والمجلد ← Commit
   ثم Settings ← Pages ← Branch: main ← Save

5) الألوان والخط
   تتغير من أعلى ملف style.css (قسم :root).
